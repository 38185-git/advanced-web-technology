# Демонстрация Lab 8

Для защиты последней лабораторной достаточно показать GraphQL в GraphiQL:

http://127.0.0.1:8000/graphql

## 1. Запрос курсов

```graphql
{
  courses(limit: 2) {
    id
    title
    level
  }
}
```

## 2. My Courses

```graphql
{
  student(id: 2) {
    name
    enrollments {
      course {
        title
        credits
        level
      }
    }
  }
}
```

## 3. Мутация createStudent

```graphql
mutation {
  createStudent(input: {name: "Test Student", email: "test@example.com"}) {
    student { id name email }
    userErrors { code message }
  }
}
```

## 4. Ошибка валидации

```graphql
mutation {
  createStudent(input: {name: "N", email: "bad"}) {
    student { id name }
    userErrors { code message }
  }
}
```

Ожидается ошибка `INVALID_NAME`. Ошибки GraphQL возвращаются в `userErrors`.
